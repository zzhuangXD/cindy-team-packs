# Cindy & friends — Team Pack

一个用交互式 3D 金属卡包介绍 Muses、Hermes、Ruby 和 Hecate 的团队页面。窄长的深莓红包装带有压封纹、锯齿边和随视角移动的条形反光。

[打开在线 Demo](https://zzhuangxd.github.io/cindy-team-packs/)

## 体验

- 拖动立体卡包，查看正面、背面、袋身鼓起的厚度和封边。
- 沿包装顶部的封口滑块向右划开；控件跟随 3D 袋口位置。也可点击「直接拆开」。
- 悬停或按住封口时，包装会稳住；手势方向沿着袋口倾斜角度计算。
- 封边随着手势卷起，再飞离袋身；袋口张开，包装下落，四张成员卡先成叠抽出，再依次展开并轻轻回弹。
- 点击 3D 卡片或成员名字，拖动查看卡片，翻面阅读介绍。
- 支持重新开包、上下成员切换、键盘操作、可选合成音效和减少动画偏好。
- 手机支持手指旋转、撕封口、选择和翻卡；页面允许自然纵向滚动。
- WebGL 无法使用时，保留头像、成员资料、成员切换和正反面内容的简化浏览入口。

## 卡面

使用这四位伙伴的现有头像，原创设计卡面和卡背：

| 成员 | 身份与职责 | 卡面元素 |
| --- | --- | --- |
| Muses | 绘画与视觉创作 | 珊瑚色笔触、抽象图形、艺术印章 |
| Hermes | 文档架构与知识组织 | 叠放的纸页、信息线条、鼠尾草绿 |
| Ruby | 只会喵喵叫的阿比西尼亚小公主 | 小王冠、爪印、玫瑰色花边 |
| Hecate | 交互原型与工程实现 | 轨道、节点、紫色与青柠点缀 |

## 实现

Three.js 实时渲染参数化的袋体网格。袋身中央较平，侧边有压褶槽，封口与角部有应力褶皱。独立的印刷、金属度和粗糙度贴图区分油墨与底膜；暗环境和条形柔光面形成金属明暗反射。

顶部封口独立建模，手势推进时逐段卷曲。开包经过撕封、张口、成叠抽卡、错峰展开四段。包装保持不透明并向下离场，卡片在袋内的部分沿袋口平面裁切；卡片共享深度展开进度，保持前后层次，同时错开横向位置与转角。整个过程不依赖预渲染视频。

卡片有独立正反面纹理与倒角厚度。头像、卡面文字、图形都在本地生成纹理，页面不依赖外部字体、图床或运行时后端。四张头像总计约 810 KB。

## 开发与验证

需要 Node.js 22.12+ 或 24。

```sh
npm ci
npm run dev
npm run build
npm test
```

`npm run build` 将部署文件输出到 `docs/`；GitHub Pages 使用 `main /docs`。

浏览器验收脚本：

```sh
npm run test:browser
npm run test:motion
npx playwright install webkit
npm run test:webkit
```

Chrome 验收默认使用 macOS 的 `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`。WebKit 验收使用 Playwright 安装的浏览器。可以通过 `DEMO_URL` 指向线上站点。

验收覆盖桌面、390×844 手机、320×568 窄屏、844×390 横屏、WebKit 手机视口和减少动画偏好。脚本检查真实鼠标/触摸拖动、沿倾斜袋口撕封、拆封中断复位、展开、3D 卡片选择、翻面、四位成员、重新开包、键盘操作、图片请求和横向溢出。动画测试固定时钟逐帧检查袋体离场、成叠抽出、错峰展开、画布高度稳定及封口控件位置。

浏览器手机视口模拟不等同于全部实体手机实测。
